Wisdom Generator — design specification

DESIGN DIRECTION — "quiet library"
The quote is the product, so it gets the whole stage and the only serif in the app.
Everything that is not the quote is metadata: small, monospaced, uppercase, tracked
wide, in muted-foreground. One accent hue (brass) carries the primary button, the
decorative quote mark and the loading dots — nowhere else. Warm bone paper in light,
deep blue-slate ink in dark; warm off-white text in both. Panels are square-ish
(4px) because they read as pages; controls are rounded (8px) because they read as
controls. No gradients on the background, no illustration, no emoji, no second
shadow.

FONT STACKS (system only, no network)
  display  Georgia, "Iowan Old Style", "Times New Roman", serif
  ui       ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, sans-serif
  mono     ui-monospace, "SF Mono", SFMono-Regular, Menlo, Consolas, monospace

TYPE SCALE
  heading    44px / 1.08 / -0.015em / display 400          (32px below 640px)
  quote      32px / 1.34 / -0.005em / display 400          (26px below 640px)
  empty line 26px / 1.34 / display 400 italic / muted-foreground
  author     14px / ui 600
  control    14px / ui 500 (select), ui 600 (button)
  body       15px / 1.5 / ui 400
  meta       11px / 1.4 / 0.13em tracking / UPPERCASE / mono 400
  error text 13px / 1.55 / mono 400
  Never set mono above 13px. Never set the serif below 26px.

SPACING SCALE (4px base — only these steps)
  4 / 8 / 12 / 16 / 24 / 32 / 44 / 64
  column gap 32 · head gap 12 · panel padding 44 32 32 · controls gap 8

RADII        panel 4px · control 8px (= --radius rounded down) · dots 50%
BORDERS      1px hsl(var(--border)) everywhere; error panel 1px destructive/45%
SHADOWS      panel   0 18px 44px -28px hsl(225 30% 8% / 0.30)
             button  0 8px 22px -12px hsl(var(--primary) / 0.55)
             Exactly two. Disabled button drops its shadow.
MOTION       hover/focus 160ms cubic-bezier(.2,0,.2,1)
             quote arrival 240ms fade + 6px rise
             loading dots 1s opacity pulse, 0.15s stagger
LAYOUT       640px centred column inside the 1280px target; panel min-height 196px
             so the three short states do not change the button's position.
FOCUS        2px hsl(var(--ring) / 0.7) ring, 2px offset, on button and select.
ICONS        none required; lucide-react optional for a 14px chevron on the select
             (the CSS caret below is the no-dependency default).

BELOW 640px  Column gap 24. Heading 32px, quote 26px, mark 68px. Panel padding
             32 24 24, min-height 168px. Controls stack vertically, select above
             button, both full width at 48px tall. Nothing is hidden or moved.

COMPONENT MAP (boundaries unchanged)
  WisdomGenerator  .wg + .wg-head + .wg-panel wrapper + .wg-controls
  QuoteDisplay     .quote-mark + .quote-body
  LoadingMessage   .wg-loading
  ErrorMessage     .wg-error
  The select is a native <select> owned by WisdomGenerator. Its value is passed
  to the fetch as the author filter; "Any author" sends no filter.
